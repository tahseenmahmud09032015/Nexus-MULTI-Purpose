## 🚀 What is NEXUS?

**Nexus-MULTI-Purpose** is a lightweight, zero-dependency, ultra-fast real-time interactive command-line dashboard and QEMU-powered Virtual Machine manager. Designed specifically for advanced Linux users, developers, and server administrators operating directly from terminals and mobile SSH environments (like Termux).

---

## ✨ Features

* **50+ Interactive Menu Options:** Categorized across System Diagnostics, Networking, Process Security, File System Maintenance, and Development Utilities.
* **500+ System Command Engine:** Integrated dynamic search engine that parses and executes system binaries straight from your `$PATH`.
* **Multi VPS & VM Manager:** Built-in QEMU and cloud-init virtualization manager to deploy, configure, start, and control multi-OS virtual machines (Ubuntu, Debian, Fedora, AlmaLinux, Rocky, CentOS).
* **Mobile & Terminal Safe:** Fully formatted with carriage-return stripping (`\r`) to ensure flawless rendering across mobile SSH clients and custom terminal containers.
